# University Management System

A Java-based desktop application designed to help manage university records electronically and reduce manual administrative work.

## Features

- Student and teacher record management
- Database connectivity for storing and retrieving records
- Support for university administration workflows
- A foundation for reducing paper-based record keeping

*Confirm each feature against the application source code before relying on this documentation.*

## Technologies

- Java
- MySQL Connector/J
- Apache Ant build configuration (`build.xml`)

## Project Files

- `build.xml` — Build configuration for Apache Ant
- `manifest.mf` — Java application manifest
- `mysql-connector-java-8.0.27.jar` — MySQL JDBC driver
- `rs2xml.jar` — Additional Java library

## Getting Started

1. Clone or download this repository.
2. Install a compatible Java Development Kit (JDK).
3. Configure the database and connection settings required by the source code.
4. Open the project in a Java IDE or inspect the Ant build configuration.
5. Follow the project's configured build and run instructions.

*The complete source code and database setup should be verified before attempting to run the application.*
